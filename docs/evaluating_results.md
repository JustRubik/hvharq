# Đánh giá kết qủa

## Cách đánh giá

### Demo

* Demo cho thầy/các bạn bằng cách chạy code và in màn hình console
* Thông số đánh giá bao gồm:
    * Thông số cài đặt: tỉ lệ lỗi, độ dài chuỗi đầu vào, v.v
    * Số packets đúng / tổng số packet
    * Số lần gửi lại
* Sau đó giải thích cách HARQ hoạt động.

### Đánh giá thông số

* Đánh giá/so sánh kết qủa của harq và arq dựa trên cùng dữ liệu, kênh truyền, xác suất lỗi
* Tính toán hiệu suất harq so với arq

## Phần nhìn

* Kết qủa in ra file text theo 1 format nhất định rồi sử dụng 1 chương trình python để hiển thị đồ thị
* Tránh animation (không cần thiết trong dự án)
